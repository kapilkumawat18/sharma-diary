# Sharma Diary Manufacturers — Demo Website

A concept/demo landing page prepared as a sales prototype for Sharma Diary Manufacturers, Jaipur.

## Included
- Responsive one-page website
- Product showcase sections
- About/brand section
- WhatsApp enquiry CTA
- Mobile navigation
- Scroll reveal animations
- No framework required

## Run
Open `index.html` in a browser.

## Before presenting to the business
Replace the illustrated product placeholders with the company's actual product photos and update the product categories/details after confirming them with the owner.

This is a demo concept, not an official website.
